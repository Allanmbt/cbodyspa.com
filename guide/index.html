CBODY GO คู่มือ

ข้อควรรู้สำหรับพนักงาน

กรุณาอ่านก่อนเริ่มงาน

1. รูปแบบการทำงาน

ระบบใหม่ใช้การแชทคุยกับลูกค้าโดยตรง

เมื่อมีออเดอร์เข้า คุณต้องเป็นคนทักลูกค้าก่อน ไม่ใช่รอแอดมินส่งงานให้เหมือนเดิม

ตอนนี้ไม่มีเวลางานตายตัว

คุณสามารถกดออนไลน์/ออฟไลน์ได้ตามต้องการ

คำอธิบายหลังเลิกงาน

เมื่อกดออฟไลน์แล้ว ระบบจะมีช่วงพักสุ่ม 6–8 ชั่วโมงก่อนจะเข้างานได้อีกครั้ง

เพื่อให้คุณได้พักผ่อนอย่างเหมาะสม เราไม่สนับสนุนการทำงานหนักจนเกินไป เพราะต้องการให้คุณมีสภาพพร้อมให้บริการลูกค้า

2. ระบบตำแหน่งและกฎการออนไลน์

  • เมื่อคุณกด「เริ่มงาน」แอปจะดึงตำแหน่งของคุณอัตโนมัติ
  • หากคุณขยับตำแหน่งไปหลายร้อยเมตร ระบบจะอัปเดตให้เอง หรือกดรีเฟรชได้

ข้อกำหนดเรื่อง Live Location

  • ระหว่างออนไลน์ทำงานไม่ต้องส่ง Live Location ใน Telegram แล้วเพราะแอปอัปเดตตำแหน่งให้เอง
  • แต่เมื่อคุณกดออฟไลน์เลิกงานแล้วยังต้องส่ง Live Location ในกลุ่ม Telegram เหมือนเดิมเพื่อให้ทีมสามารถตรวจสอบความปลอดภัยหลังเลิกงานได้

3. การตั้งค่าที่ต้องทำก่อนเริ่มใช้ครั้งแรก

1. ตั้งค่าระยะทางที่คุณรับงานได้

  • ใช้ระยะทางจริงตามเส้นทางรถยนต์
  • ถ้าลูกค้าอยู่นอกรัศมีที่ตั้งไว้ ระบบจะไม่ให้ลูกค้าจองคุณ

ห้ามยกเลิกงานเพราะ「ไกลเกินไป」เพราะมีผลต่อคะแนนและการจัดอันดับ

เคล็ดลับ: ใช้แอปเรียกรถเช็กดูก่อนว่าระยะไหนที่คุณสะดวก แล้วค่อยตั้งค่าในระบบ

2. เพิ่มบัญชีรับเงินของคุณ

เส้นทาง: 【โปรไฟล์】→【ศูนย์การเงิน】→【จัดการบัญชีรับเงิน】

ใช้สำหรับให้แพลตฟอร์มโอนเงิน RMB ให้คุณในกรณีถอนเงิน

3. เปิดการแจ้งเตือน + อนุญาตตำแหน่ง

กรุณาตรวจสอบ:

  • เปิดอนุญาตการแจ้งเตือนและตำแหน่งให้แอป
  • เปิดเสียง/สั่นให้ดังพอ เพื่อไม่พลาดงานใหม่

เมื่อมีออเดอร์ใหม่ จะมีแจ้งเตือนทั้งจากแอป CBODY GOและกลุ่ม Telegram

หากลูกค้ายกเลิก ระบบจะแจ้งในกลุ่มเช่นกัน

4. ขั้นตอนก่อนเลิกงาน (สำคัญมาก)

ก่อนเข้านอนหรือหยุดงานทุกครั้ง กรุณา:

1. กดออฟไลน์ในแอป

2. ตรวจสอบว่าออเดอร์ทุกงานถูกทำจนเรียบร้อยแล้ว (เสร็จสิ้นหรือถูกยกเลิกตามระบบ)

3. ส่ง Live Location ในกลุ่ม Telegram เพื่อให้ทีมสามารถตรวจสอบความปลอดภัยหลังเลิกงานได้

สำคัญมาก — กรุณาอ่านคู่มือทั้งหมด

โปรดเปิดดู「เมนูสารบัญ」มุมขวาบน แล้วอ่านทุกหัวข้อให้ครบถ้วน
เพื่อให้คุณเข้าใจวิธีใช้งานแอป กฎการทำงาน การรับงาน และเรื่องการชำระเงิน
จะได้ไม่กระทบสิทธิ์และรายได้ของคุณ
