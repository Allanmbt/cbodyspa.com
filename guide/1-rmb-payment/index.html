CBODY GO คู่มือ

1. วิธีใช้ระบบรับ RMB ของแพลตฟอร์ม

เข้าใช้งาน: 【รายละเอียดออเดอร์】→【รับชำระ】

ระบบรับชำระ RMB ของแพลตฟอร์มคืออะไร?

ระบบรับชำระ RMB ใช้ในกรณีที่ลูกค้าไม่สามารถจ่ายเงินสดหรือโอนเงินไทยได้ คุณสามารถให้ลูกค้าชำระเป็นมัดจำ/จ่ายเต็ม/ทิปผ่าน WeChat หรือ Alipay ของแพลตฟอร์มแทนคุณได้

ทำไมต้องใช้ระบบรับชำระของแพลตฟอร์ม?

  • หลังลูกค้าชำระเงินและตรวจสอบแล้ว จะปรากฏในบัญชี RMB
  • สะดวกให้ฝ่ายการเงินตรวจสอบ ถอนเงินได้เร็วขึ้น
  • พนักงานสามารถตรวจสอบบันทึก RMB ในออเดอร์ได้ตลอดเวลา

1. ใช้ QR Code ของแพลตฟอร์มรับชำระ (แนะนำ)

1. ขั้นตอนการใช้งาน

  1. เปิด【รายละเอียดออเดอร์】→【รับชำระ】
  2. เลือกรายการรับชำระ (มัดจำ, จ่ายเต็ม, ทิป ฯลฯ)
  3. ระบบจะสร้างQR Code WeChat/Alipay เฉพาะของแพลตฟอร์ม
  4. แสดง QR Code ให้ลูกค้าสแกนและชำระเงิน
  5. หลังลูกค้าชำระสำเร็จ ระบบจะบันทึกเข้าบัญชี RMB ของคุณโดยอัตโนมัติ
  6. รายละเอียดออเดอร์จะแสดงบันทึกการรับชำระนี้

2. ข้อควรระวัง

  • หลังลูกค้าชำระเงิน กรุณาเช็กในรายละเอียดออเดอร์ว่ามีบันทึกการรับชำระหรือไม่
  • หากลูกค้าบอกว่าชำระแล้วแต่ระบบไม่แสดง กรุณาติดต่อฝ่ายบริการลูกค้าเพื่อตรวจสอบ

2. ลูกค้าโอนเข้าบัญชีส่วนตัว (เพิ่มบันทึกด้วยตัวเอง)

หากลูกค้าโอนเงินตรงเข้า WeChat/Alipay ส่วนตัวของคุณ คุณต้องเพิ่มบันทึก RMB ด้วยตัวเอง

1. ขั้นตอนการใช้งาน

  1. เปิด【รายละเอียดออเดอร์】→【รับชำระ】
  2. กด【เพิ่มบันทึก RMB (เพิ่มรายการ RMB)】
  3. เลือกรายการรับชำระ (มัดจำ, จ่ายเต็ม, ทิป ฯลฯ)
  4. ใส่จำนวนเงินที่รับจริง
  5. อัปโหลดภาพหลักฐานการโอนเงิน (ต้องอัปโหลด)
  6. กดยืนยัน รอฝ่ายการเงินตรวจสอบ
⚠️
ต้องอัปโหลดภาพหลักฐานการโอนเงิน มิฉะนั้นฝ่ายการเงินจะตรวจสอบไม่ได้ บันทึกจะถูกปฏิเสธ

2. ข้อกำหนดหลักฐานการโอนเงิน

  • ภาพหน้าจอต้องชัดเจน มองเห็นจำนวนเงิน เวลาโอน

3. คำอธิบายการตรวจสอบ

  • ฝ่ายการเงินจะตรวจสอบหลักฐานการโอนเงินที่คุณอัปโหลดภายใน24 ชั่วโมง
  • หลังตรวจสอบผ่าน จำนวนเงินจะบันทึกเข้าบัญชี RMB ของคุณ
  • หากถูกปฏิเสธ จะมีเหตุผลในหมายเหตุ กรุณาอัปโหลดใหม่ตามที่กำหนด

3. คำอธิบายรายการรับชำระ

มัดจำ (มัดจำ)

มัดจำที่ลูกค้าชำระเมื่อจอง โดยทั่วไปคือส่วนหนึ่งของค่าบริการ

จ่ายเต็ม (ชำระเต็ม)

ลูกค้าชำระค่าบริการทั้งหมด

ทิป (ทิป)

ทิปพิเศษที่ลูกค้าให้ ส่วนนี้100% เป็นของคุณ ไม่คิดค่าคอมมิชชั่น

อื่นๆ (อื่นๆ)

รายการรับชำระประเภทอื่น เช่น ค่าบริการขยายเวลา ค่าบริการเพิ่มเติม ฯลฯ

4. ดูบันทึกการรับชำระ

เส้นทาง: 【รายละเอียดออเดอร์】→ เลื่อนลงไปยังพื้นที่บันทึกการรับชำระ

หน้ารายละเอียดออเดอร์แต่ละหน้าด้านล่างจะแสดงบันทึกการรับชำระทั้งหมด ประกอบด้วย:

  • รายการรับชำระ (มัดจำ, จ่ายเต็ม, ทิป ฯลฯ)
  • จำนวนเงินที่รับ
  • วิธีรับชำระ (แพลตฟอร์มรับแทน หรือ บัญชีส่วนตัว)
  • เวลารับชำระ
  • สถานะการตรวจสอบ (ยืนยันแล้ว, กำลังตรวจสอบ, ปฏิเสธแล้ว)
💡
แนะนำให้เช็กบันทึกการรับชำระว่าครบถ้วนหรือไม่หลังจากออเดอร์เสร็จ หากมีสิ่งที่หลุดลอยให้เพิ่มทันที

5. ข้อควรระวังสำคัญ

1. หากออเดอร์เสร็จเกิน 1 ชั่วโมง จะไม่สามารถเพิ่มบันทึก RMB ได้

ต้องเพิ่มทันทีหลังลูกค้าชำระเงิน เพื่อไม่ให้เกิดปัญหาเวลาฝ่ายการเงินตรวจสอบในวันถัดไป

2. ต้องเพิ่มบันทึกในออเดอร์ที่ถูกต้องเท่านั้น

ห้ามกดผิดออเดอร์ เพราะจะทำให้การตรวจสอบผิดพลาด

3. ค่าธรรมเนียม 1%

เป็นค่าธรรมเนียม WeChat/Alipay จริง แพลตฟอร์มไม่เก็บค่าบริการเพิ่ม

4. แพลตฟอร์มรับชำระเฉพาะ RMB เท่านั้น

ไม่รับแทนในกรณี:

  • เงินสดไทย
  • โอนเงินไทยเข้าบัญชีไทย
  • PromptPay
  • หรือช่องทาง THB อื่นๆ

เงินไทยทุกประเภท ให้พนักงานเป็นผู้รับเองทั้งหมด

คำถามที่พบบ่อย

Q1: หากลูกค้าชำระหลายครั้ง จะบันทึกอย่างไร?

A: ทุกครั้งที่รับชำระต้องเพิ่มบันทึกหนึ่งรายการ เช่น ลูกค้าชำระมัดจำก่อน แล้วชำระส่วนที่เหลืออีกครั้ง ก็ต้องเพิ่มบันทึก RMB สองรายการ

Q2: หลังส่งบันทึก RMB แล้วสามารถแก้ไขได้ไหม?

A: ไม่สามารถแก้ไขโดยตรงได้ หากกรอกผิด กรุณาติดต่อฝ่ายบริการลูกค้าพร้อมแจ้งหมายเลขออเดอร์และสถานการณ์ ฝ่ายบริการลูกค้าจะช่วยปรับให้

Q3: หากสงสัยยอดผิด หรือบันทึกผิด ทำอย่างไร?

A: ให้แจ้งในกลุ่ม Telegram พร้อมเลขออเดอร์ ทีมงานจะช่วยตรวจสอบให้
