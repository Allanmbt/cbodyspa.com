# SEO 关键词策略总结

> **重要：** 此文档总结了 CBODY 网站的 SEO 关键词策略，确保 AI 在创建页面时使用正确的关键词，避免关键词蚕食和过度优化。

---

## 🎯 核心策略

### 平台定位
- **平台类型**: On-demand service marketplace
- **核心服务**: Outcall / Mobile / In-home massage
- **核心地区**: Thailand (Bangkok 为主，Chiang Mai、Pattaya 为辅)
- **转化目标**: Booking / App install / Contact
- **搜索意图**: Transactional（交易型，非信息型）

---

## 📍 关键词分层策略（避免关键词蚕食）

### 原则：一个关键词 = 一个主页面

| 页面类型 | 主关键词 | 关键词密度 | 示例 |
|---------|---------|-----------|------|
| **首页** | `outcall massage bangkok` | 0.5-1.5% | 唯一使用此关键词作为主要目标 |
| **服务页** | `mobile massage bangkok`<br>`24 hour outcall massage bangkok`<br>`in-home massage bangkok` | 0.5-1% | 每个服务页选择一个独特关键词 |
| **地区页** | `outcall massage sukhumvit`<br>`outcall massage silom`<br>`outcall massage asok` | 0.5-1% | 一个地区 = 一个独特关键词 |
| **博客文章** | `how to book outcall massage bangkok`<br>`outcall massage bangkok guide`<br>`what to expect outcall massage bangkok` | 0.3-0.8% | 使用长尾关键词（3-5 个词） |
| **技师页面** | 技师名字 + 服务类型 | 避免主关键词 | 例如："Nisha - Thai Massage Therapist" |
| **关于/联系** | 无 | 避免主关键词 | 自然提及品牌和服务 |

## 🔗 内链策略（蜘蛛网结构）

### 内链原则
1. **首页是核心**：所有页面都应该链接回首页
2. **相关页面互链**：博客文章之间、服务页面之间互相链接
3. **使用描述性锚文本**：不要用 "click here"，使用关键词
4. **每个页面 3-5 个内链**：不要过多或过少

### 内链结构示例

```
首页 (outcall massage bangkok)
│
├── 服务页 1 (mobile massage bangkok)
│   ├── 博客 1 (how to book mobile massage)
│   └── 博客 2 (mobile massage benefits)
│
├── 服务页 2 (24 hour outcall massage bangkok)
│   └── 博客 3 (late night massage tips)
│
├── 地区页 1 (outcall massage sukhumvit)
│   ├── 博客 4 (best massage sukhumvit)
│   └── 技师页面 (therapists in sukhumvit)
│
└── 地区页 2 (outcall massage silom)
    └── 博客 5 (massage hotels silom)
```

### 锚文本最佳实践

**✅ 好的锚文本：**
```html
<a href="/">outcall massage bangkok</a>
<a href="/">professional outcall massage in Bangkok</a>
<a href="/services/mobile-massage">mobile massage service</a>
<a href="/locations/sukhumvit">outcall massage in Sukhumvit</a>
```

**❌ 不好的锚文本：**
```html
<a href="/">click here</a>
<a href="/">homepage</a>
<a href="/">read more</a>
```

## 🚫 避免关键词蚕食（Keyword Cannibalization）

### 什么是关键词蚕食？
多个页面竞争同一个关键词，导致谷歌不知道该排名哪个页面。

### 如何避免：

1. **一个关键词 = 一个主页面**
   - `outcall massage bangkok` → 仅首页
   - `mobile massage bangkok` → 仅服务页
   - `outcall massage sukhumvit` → 仅 Sukhumvit 地区页

2. **其他页面可以提及，但不作为主要目标**
   - 博客文章可以提及 "outcall massage bangkok"
   - 但主要目标是长尾关键词

3. **使用内链明确页面层级**
   - 首页 ← 最重要
   - 服务页、地区页 ← 次要
   - 博客文章 ← 支持内容

## 🚨 避免过度优化

### 谷歌判定过度优化的信号：
- ❌ 关键词密度 > 2%
- ❌ 关键词在每个段落都出现
- ❌ 关键词使用不自然（强行插入）
- ❌ 多个页面使用相同的 Title 和 Description
- ❌ 锚文本过度优化（所有内链都用相同关键词）

### 安全的关键词密度：
- **首页**: 0.5-1.5%
- **服务页**: 0.5-1%
- **地区页**: 0.5-1%
- **博客文章**: 0.3-0.8%

### 计算方法：
```
关键词密度 = (关键词出现次数 / 总字数) × 100%

示例：
文章 1000 字
"outcall massage bangkok" 出现 10 次
密度 = (10 / 1000) × 100% = 1%  ✅ 安全
```

## 📊 页面创建检查清单

创建任何页面前，确保：

### 关键词策略
- [ ] 确定页面类型（首页/服务页/地区页/博客）
- [ ] 选择正确的主关键词（不与其他页面冲突）
- [ ] 检查关键词密度（不超过安全范围）
- [ ] 关键词使用自然（不强行插入）

### 内链策略
- [ ] 包含 3-5 个内链
- [ ] 链接到首页（使用描述性锚文本）
- [ ] 链接到相关服务页或地区页
- [ ] 使用关键词作为锚文本（不用 "click here"）

### 避免过度优化
- [ ] 关键词密度在安全范围内
- [ ] 关键词使用自然流畅
- [ ] 没有与其他页面竞争相同关键词
- [ ] Title 和 Description 独特（不重复）

---

## 🎯 总结

**核心原则：**
1. **一个关键词 = 一个主页面**（避免关键词蚕食）
2. **关键词密度 < 2%**（避免过度优化）
3. **使用内链形成蜘蛛网结构**（提升 SEO）
4. **博客文章使用长尾关键词**（不与首页竞争）

**记住：**
- 首页 = `outcall massage bangkok`（唯一）
- 服务页 = 独特的服务关键词
- 地区页 = 独特的地区关键词
- 博客 = 长尾关键词（3-5 个词）
