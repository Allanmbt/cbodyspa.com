CBODY 内部服务标准

Wellness 版草案 · 用于培训与上架审核 · 不对外公开

📋 0. 通用合作规则

车费

  • 车费全部归技师
  • 必须合理收取,严禁乱要价
  • 详见《车费制度》

定金

  • 由技师自行向顾客收取
  • 优先用自己的泰国收款码,也可用平台代收款(微信/支付宝)
  • 通常收取500-1,000 THB
  • 车费<200 THB、老顾客、高等级会员可考虑不收

提成

  • RELAX LITE、COCO FLOW: 55%
  • 其余 Wellness 项目: 65%
  • 平台有权调整并另行通知

上架前提

必须完成相应项目培训并通过考核后,才能开通该服务。若顾客反映手法与说明不符或体验明显低于标准,平台可随时取消该服务权限。

🎯 1. 分类概览

🌿 1.1 Wellness (轻养馆)

定位: 上门按摩 / SPA / 放松与情绪价值结合的服务

🎒 通用装备

  • • 一次性床单、枕巾
  • • 按摩油 / 啫喱
  • • 洗手消毒用品
  • • 手机 + 小音箱(音乐)
  • • 基础工作服(需和管理员确认)

📝 通用流程

到达 → 环境确认 → 简短沟通身体状况与禁忌 → 洗手消毒 → 按照项目标准执行 → 简短收尾与整理

⚠️ 通用边界: 避免危险动作;如顾客提出超出项目说明或违规要求,必须回到标准流程或婉拒终止。

🏠 1.2 HomeHub (萌宅社)

当前分类 处于内部设计阶段,具体项目标准与提成比例尚未对技师开放。现阶段 不得对外宣传或自行接 HomeHub 类订单,最终版本以平台正式通知为准。

✈️ 1.3 Journey (悦途社)

当前分类 处于试验与规划阶段,尚未开放技师自由报名。所有城市陪伴 / Day Trip / Travel Private 相关规则,将在后续统一发布独立制度。

2.2 COCO FLOW

提成 55%

2.6 SILK ONSEN VOYAGE

提成 65%

定位: 带日式温泉仪式感的全身丝滑项目,含鸳鸯浴流程

📚 前置条件

必须完成本项目专项培训,通过考核后才能上架

⚠️ 硬性要求

  • • 服务中必须包含标准化鸳鸯浴流程(按培训 SOP 执行)
  • • 需要使用专用防滑垫/防水垫,确保环境安全

👔 着装与状态

按培训要求,本项目为全身无服装的操作形态,但需始终保持自然与专业,不做夸张表演

📝 流程要点

浴前沟通 → 共浴流程(按SOP) → 上垫丝滑推抚 → 清理油脂 → 收尾互动与整理

🛡️ 风险控制
